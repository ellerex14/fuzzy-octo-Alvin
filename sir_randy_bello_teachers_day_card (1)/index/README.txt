SIR RANDY BELLO — TEACHERS' DAY LETTER

1. Keep index.html as one single file.
2. Double-click index.html to open it in Chrome or Edge.
3. Click “Open the letter” to see the animated letter.
4. Use the top-right button to switch between dark mode and light mode.
5. The instructor photo is embedded directly in the HTML, so no separate image file is needed.
6. Edit index.html in Notepad or VS Code to customize the letter/signature.

HTML, CSS, and JavaScript are all together in index.html. No external libraries required.
